# 三种推理方式延迟对比

测试日期：2026-10-29。

## 对比对象

为区分“部署带来的模型复用收益”和“TensorRT 带来的计算加速”，本次固定使用同一
Community-1 模型、同一 GPU 和同一批音频，比较以下三版：

1. **未部署 / PyTorch**：每个音频启动一个新的 Python 进程，重新导入依赖、加载模型、推理并写出结果。
2. **已部署 / PyTorch**：启动一个本地 HTTP 服务，PyTorch 模型只加载一次，11 个请求连续复用。
3. **已部署 / TensorRT**：启动一个本地 HTTP 服务，TensorRT 引擎和模型只加载一次，11 个请求连续复用。

两个服务分别在全新的独立 Python 进程中启动。服务启动时间从创建进程开始，计到
`GET /health` 返回 ready；不存在两个服务共享 Python 模块缓存的情况。未额外执行或隐藏预热请求，
第一条正式请求包含该后端的首次使用开销。

端到端请求时间包括客户端读取文件、上传到本机回环地址、排队与轮询、GPU 推理、结果写盘和
结果 JSON 获取。服务端纯推理时间由服务内部的 `perf_counter` 记录。

## 数据

共 11 条、1,181.648254 秒音频，合计约 19.69 分钟：

- Huawei 样例：10 秒和 181.648254 秒各一条；
- pyannote 测试样例：30 秒一条；
- 本地已有 Huawei 数据两条、AMI 数据五条和另一条本地音频，各裁取前 120 秒，共八条。

120 秒片段统一转换为 16 kHz、单声道 PCM WAV。裁剪音频、原始音频和逐任务完整输出均位于
被 `.gitignore` 排除的 `outputs/`，不会上传 GitHub；仓库只保留不含音频内容的聚合结果。

## 汇总结果

| 模式 | 服务启动 | 11 条请求端到端合计 | 含一次服务启动的整批总时长 | 相对未部署加速 | 纯推理 RTF |
|---|---:|---:|---:|---:|---:|
| 未部署 / PyTorch | 每条内含，重复 11 次 | 140.126731 秒 | 140.126731 秒 | 1.00× | 0.037156 |
| 已部署 / PyTorch | 7.823096 秒 | 40.351983 秒 | 48.175079 秒 | 2.91× | 0.033294 |
| 已部署 / TensorRT | 8.335278 秒 | 11.762536 秒 | 20.097814 秒 | 6.97× | 0.008920 |

如果服务已经启动，只比较请求阶段：

- 已部署 PyTorch 相对未部署端到端累计快 **3.47×**；
- 已部署 TensorRT 相对未部署端到端累计快 **11.91×**；
- 已部署 TensorRT 相对已部署 PyTorch 请求阶段快 **3.43×**；
- 把两者各自的一次完整服务启动也计入，TensorRT 版仍比部署 PyTorch 快 **2.40×**。

未部署版 11 次端到端时间中，纯推理合计 43.904896 秒，重复的进程启动、依赖导入、模型加载和
结果写出等开销合计 96.221835 秒，平均每个文件约 8.747 秒。部署 PyTorch 的主要收益来自消除
这部分重复开销；TensorRT 则在此基础上把纯推理合计进一步从 39.342280 秒降至 10.540824 秒。

## 输出一致性

每条音频都对 `complete` 和 `non_conflict` 的全部分段进行规范化 SHA256 指纹比较。
33 次推理的 `(start, end, speaker)` 输出全部一致：

| 模式 | 与未部署 PyTorch 一致 |
|---|---|
| 未部署 / PyTorch | 是 |
| 已部署 / PyTorch | 是 |
| 已部署 / TensorRT | 是 |

这说明本轮延迟差异不是通过减少输出内容或改变分段换来的。它仍属于有限本地样本的工程回归，
不能替代跨数据集 DER 准确率评估。

## 复现

基准实现位于 `scripts/benchmark_deployment_modes.py`。脚本要求至少两个 `LABEL=PATH` 输入，
并依次运行未部署 PyTorch、部署 PyTorch 和部署 TensorRT；完整原始结果默认写入指定输出目录的
`benchmark.json`。本次完整本机记录位于：

```text
outputs/deployment_latency_benchmark_final_20261029/benchmark.json
```

该目录不纳入 Git；可提交的精简聚合证据位于
`example/deployment_latency_summary.json`。
